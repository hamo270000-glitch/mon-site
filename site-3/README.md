# Site 3

Nouveau projet, en ligne sur https://hamo270000-glitch.github.io/mon-site/site-3/

Même base que le Site 2 : **React**, **Vite**, **Tailwind CSS**, **React Bits**, **GSAP** et **Lenis**.
Le contenu reste à choisir.

## Organisation
- `source/` : le code à modifier (page principale : `source/src/App.tsx`, couleurs dans `source/src/index.css`).
- `source/src/components/reactbits/` : composants animés React Bits déjà disponibles.
- `index.html` et `assets/` : le site construit, publié par GitHub Pages. **Ne pas modifier à la main.**

## Après chaque modification
```
cd site-3/source
npm install      # la première fois seulement
npm run build    # reconstruit site-3/index.html et site-3/assets/
```
