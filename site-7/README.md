# Site 7 · Maison Grain (démo)

Site de démonstration demandé par l'utilisateur : « fais un site avec ui-ux-pro-max, invente tout, je veux juste voir le rendu ».
Marque, cafés, prix et avis sont **inventés** (un bandeau le dit en haut de la page).

En ligne : https://hamo270000-glitch.github.io/mon-site/site-7/

## Design (généré par ui-ux-pro-max)
- Style « Liquid Glass » : barre de navigation et cartes en verre dépoli.
- Couleurs : sombre premium (#0f0d0b, #1c1917) + or (#c9a35b / #a16207), crème #f6f1e8.
- Polices : Cormorant (titres, italique) + Montserrat (texte), hébergées dans `fonts/`.
- Animations GSAP (dans `vendor/`) : titres qui montent mot par mot (SplitText), compteurs, parallaxe du héros, bandeau des origines, cartes en vague, défilement horizontal épinglé des 4 étapes, grain de café qui vole jusqu'au panier, prix de l'abonnement qui s'anime. Défilement doux avec Lenis.

## Fichiers
Une seule page `index.html` (HTML + CSS + JS), sans étape de construction.
